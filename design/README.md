# Макеты переоформления

Три направления, один и тот же экран — конструктор заявления, одно и то же
заявление по делу А63-1672/2025. Меняется только оформление, чтобы сравнивать
было нечего, кроме него.

Файлы открываются двойным щелчком, ничего не требуют и никуда не ходят.

* `1-бумага.html` — белый лист, чёрный текст, ни карточек, ни теней.
  Интерфейс — мелкий гротеск, документ — Times. Цвет один, красный,
  и только там, где не заполнено.
* `2-рабочая-станция.html` — плотный инструмент: панель, вкладки, три
  колонки с разделителями, строка состояния. Всё видно сразу.
* `3-тихая-типографика.html` — тепло остаётся, приёмы уходят: прямые углы,
  линии в один пиксель, иерархия только шрифтом.

Во всех трёх лист имеет настоящие пропорции A4 и настоящие поля документа
(3 см слева, 1,5 справа, 2 сверху и снизу) — те же, с какими выгружается DOCX.
Из-за этого строка получает нормальную длину, и текст перестаёт читаться
сплошной массой.

Папка временная: как только направление выбрано, она удаляется.
